# Issue Tracker

This repository uses a local Markdown tracker because there is no configured remote issue tracker. The parent issue and tickets live under `.scratch/agent-activity-dock/`.

- Parent issue: `.scratch/agent-activity-dock/issue.md`
- Tickets: `.scratch/agent-activity-dock/issues/`
- Ticket order and blocking edges are written in each ticket file.
- A ticket is ready for a fresh Agent session only after every listed blocker is complete.
