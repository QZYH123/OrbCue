# Design Language — OrbCue

designer 子代理的持久记忆。新的设计决策用一两行追加到对应小节。

## 基调

- 默认「原型」：石墨哑光 `#121416` 壳、`#eceef1` 字、细发丝线。不要黑金、不要磷光黄。
- 设置里可切换外观：原型、Fluent、Glyph、Braun、Glass。Island 与原型重复，不进主题。
- 语义色克制：工作 `#5ecf8f`、注意 `#e0a257`、失败 `#e07a7a`（各主题可换色，语义不变）。
- 字体只用系统无衬线。大数字也走同一套。 Glyph 球始终叠工作/追踪数字，不只靠点阵字形。

## 应用图标

- 构图即产品：石墨圆角砖（#21272d→#0f1318）+ 哑光球 + 绿色工作弧（#5ecf8f，约 5/8 圈）+ 右上琥珀 cue 点（#e0a257，遮罩挖孔悬浮于弧上）。无光泽、无黑金。
- 母版 `src-tauri/icons/icon.svg`（128 viewBox）；≤48px 档用加粗描边变体渲染进 icon.ico（16–256 共 7 档），icon.png 为 128px。

## 小球（56px 窗，OS region 硬裁成圆）

- CSS 球 52px；圆外禁止 drop-shadow、外扩辉光、translateY、向外 scale。
- 内圈 conic 表示工作/追踪。无旋转光泽层。
- `pulse` 只动 inset。点击 toggle 面板。

## 面板（300×400 窗）

- 顶栏大数字 + 底栏导航。列表区域 `overflow-x: hidden`，不要横向滚动条。卡片 hover 不要 translateX。
- 会话不显示 summary。标题是 Agent 名 + 同项目同 Agent 的两位序号 `01` `02`（全量列表编号，筛选不重排）。
- 项目行右侧可收起。
- 「回去」是返回箭头图标，不是「回」字。精确与否都用同一套细线圆钮，不要填工作绿。
- 连接页：一行名称+侧别，一行路径省略，右侧状态+按钮。不要字母方块图标。
- 连接页状态词仍是「已连接/可连接」。
- 审计：和动态页同一套 Agent + 序号；不显示 session hex。第二行是状态 · 项目。不记 working / idle。条数多时卡片按内容高度排列、列表滚动，不能被压成一条灰线。
- 顶栏数字与「需要你」等 meta 之间必须留 gap（各主题 6–10px）。
- 连接页导语压在 3 行内：信任信息（不下载不替换不读内容）+ 无 WSL 行为 + orb run 提示；测试锚定「orb run」「没有 WSL」两词。
- `.primary-button:disabled` 全主题统一 `opacity: .4`。
- 引导页无列表的步骤（主题、run），内容块在剩余空间垂直居中，不顶部堆叠。
