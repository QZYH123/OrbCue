# 15 — 跳回兜底加固：窗口级标注与移除模糊级联

**What to build:** 捕获式跳回只在可靠时使用并如实标注精度；删除产生非预期行为的模糊标题匹配。宁可诚实失败，不做错误跳转。

**Blocked by:** 无

**Status:** complete

- [x] `FocusResult` 增加 `precise: bool`（或等价字段）：dock 标签精确通道为 true；捕获 HWND 通道为 false。
- [x] 捕获 HWND 使用前校验：IsWindow 存活 + 窗口仍属终端类（类名/进程白名单）；任一不满足即删除记录并继续降级。
- [x] 移除项目名末段 / `source` 子串的模糊标题级联（在标题恒为发行版名的环境只产生误报与「不唯一」噪音）；deep_link 保留最高优先。
- [x] 非精确聚焦成功时，前端在会话卡片上短暂显示「已回到最近交互的窗口」；失败时文案为「找不到该会话的窗口」并附一句「用 dock run 启动可获得精确跳回」。（文案与呈现属审美部分，归主会话。）
- [x] 捕获决策逻辑（新会话 / 转入 working 时记录前台终端窗口）保持现状，不扩大捕获时机。
- [x] 行为测试：HWND 失效→降级；非终端类→降级；移除级联后不再出现「匹配不唯一」路径；`precise` 标志随通道正确变化。
