# 14 — OS 级真圆小球与更紧凑的尺寸

**What to build:** 用 Win32 window region 把小球窗口裁成真正的圆，彻底消掉圆外的残留模糊框；同时把球和面板都缩小一档。

**Blocked by:** 无

**Status:** ready

背景：当前方案是「透明方窗 + CSS 圆」。残留模糊框有两个来源：圆外边距里绘制的阴影/辉光半透明像素，以及部分 GPU/驱动组合下 WebView2 对透明窗口整个矩形的轻微底色合成。CSS 只能控制自己绘制的内容，控制不了窗口矩形本身，所以裁剪必须发生在窗口层。

- [ ] Windows 上对 ball 窗口设置圆形 region（取 HWND 调 `SetWindowRgn`）：圆外像素由系统硬裁剪，圆外点击穿透到桌面。
- [ ] CSS 圆直径比 region 小约 2px，保留抗锯齿边缘不被硬裁剪切齐；圆外不再绘制任何阴影或辉光，状态辉光改为圆内描边/内发光。
- [ ] 小球窗口从 112 缩到 64 逻辑像素（球体约 60px），计数字号分级调整，`10/12` 这类最长标签仍清晰可读，`!`/`?` 角标仍在环上且不被裁剪。
- [ ] 面板收敛到约 360×500，间距与字号同步收紧，信息层级与现有功能不变。
- [ ] DPI 缩放变化或显示器切换时，region 随窗口物理尺寸同步重建，不出现错位圆。
- [ ] 拖动与点击命中不回退；region 更新过程无可见闪烁。
- [ ] 验收：目检圆外无任何可见像素（含浅色/深色壁纸各一次）；圆外点击落到桌面而非 Dock。
