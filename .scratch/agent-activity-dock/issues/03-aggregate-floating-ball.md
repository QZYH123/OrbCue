# 03 — 显示聚合悬浮小球

**What to build:** 把聚合快照显示成固定尺寸的置顶小窗口：边框颜色表示是否有任务工作中，数字显示工作数量/追踪数量，点击或热键打开紧凑任务列表。

**Blocked by:** 02 — 接入本地 IPC 和多任务聚合

**Status:** complete

- [x] 当前环境能创建约 32–48px 的独立置顶窗口；窗口尺寸不会随计数变化抖动。
- [x] 工作数量大于零时显示工作边框色，否则显示空闲边框色。
- [x] `0/0`、`1/1`、`2/10` 等计数清晰可读，数字提供非颜色的状态线索。
- [x] 普通工作事件不会强制展开、移动或持续重绘小球。
- [x] 点击或热键可以打开任务列表；窗口聚焦源终端作为可选能力，不能阻塞列表功能。
- [x] presenter 测试通过公开快照合同，不绑定 GUI 工具包私有对象。
