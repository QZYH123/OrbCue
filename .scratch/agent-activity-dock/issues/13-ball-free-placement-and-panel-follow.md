# 13 — 小球自由摆放与面板跟随

**What to build:** 去掉松手自动吸附屏幕左右边缘的行为，小球拖到哪停在哪；任务面板始终出现在小球旁边，包括小球被拖走之后。

**Blocked by:** 无

**Status:** complete

- [x] 删除拖动结束后的自动吸附；只保留工作区边界 clamp，保证球不会被拖出屏幕找不回。
- [x] 位置持久化沿用现有 `ball-position.json`，重启后回到上次位置。
- [x] 每次打开面板都按小球当前位置重新定位：球在屏幕左半则面板出右侧，反之出左侧，上下随球对齐并 clamp。

- [x] 多显示器下面板与小球始终同屏。
- [x] 不新增设置项，不改变点击打开面板的现有行为。
- [x] 行为测试：clamp 边界、开面板选边逻辑可用文本断言覆盖；跟随/隐藏行为有验证路径。
