# 02 — 接入本地 IPC 和多任务聚合

**What to build:** 用户可以通过一个本地 CLI 发送事件，daemon 接收后维护多个任务，并正确提供 `工作数量/追踪数量` 快照。

**Blocked by:** 01 — 建立任务状态闭环

**Status:** complete

- [x] CLI 可以向当前用户专用的本地 IPC 发送开始、停止、等待、报错和重置事件。
- [x] 同时运行多个任务时，快照正确显示例如 `2/3`。
- [x] 重复事件、未知动作、非法数据、过大消息不会污染当前状态。
- [x] CLI 能快速得到 accepted/rejected 结果，不等待声音或 GUI 绘制。
- [x] 不开网络监听，不扫描 Agent 进程或终端。
- [x] 有真实 CLI → IPC → daemon → 快照集成测试。
